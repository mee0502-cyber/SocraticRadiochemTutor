# 放射化学ソクラテスチューター (SocraticRadiochemTutor)
診療放射線技師国家試験「放射化学」分野に特化した、ソクラテス式（対話型ヒント）学習支援Webアプリケーションです。

## 概要
一般的なAIチャットボットと異なり、学生が質問した計算問題に対して**「直接的な答えをすぐに教えません」**。
段階的なヒントと誘導質問を投げかけ、学生自身の力で公式を思い出し、立式し、計算させることで、国家試験に必要な「本質的な理解力と計算応用力」を養います。

---

## 主な機能
1. **ソクラテス式AIチャット**: 答えを即答せず、思考を促すヒントを1つずつ提示する対話機能。
2. **主要放射性核種データシート**: 診療放射線技師国家試験に頻出する11の主要核種（⁹⁹ᵐTc, ¹⁸F, ¹³¹I, ⁶⁰Co, ¹³⁷Cs, ⁹⁰Sr, ⁶⁷Ga, ²⁰¹Tl, ¹¹C, ¹²³I, ⁹⁰Y）の物理学的半減期・壊変モード・放出エネルギー等の情報を右側のパネルで常時参照可能。
3. **過去問テンプレート演習**: 国試の定番計算問題（減衰割合、過渡平衡時間、壊変定数など）を選択し、その解法ルートに沿った誘導対話をスタートできます。
4. **API設定 & チューターカスタマイズ**: 先生用または学生用に、APIキーの入力、使用モデルの選択、指導スタイルの厳格度（標準/ヒント極小/計算式1行ずつチェック）を変更可能。

---

## 起動方法
本アプリは**サーバー不要**で動作する静的HTMLアプリケーションです。

1. 本フォルダ内の `index.html` ファイルをダブルクリックし、Webブラウザ（Google Chrome, Microsoft Edge等）で開きます。
2. インターネット接続があれば、即座に起動します。

---

## Gemini API キーの取得方法（無料枠あり）
自由に対話を行うためには、Googleの提供する **Gemini API キー** が必要です。

1. **[Google AI Studio](https://aistudio.google.com/)** にGoogleアカウントでログインします。
2. **「Get API key」** ボタンをクリックします。
3. **「Create API key」** をクリックし、任意のプロジェクトを選択してキーを作成します。
4. 発行された `AIzaSy...` から始まるキー文字列をコピーします。
5. 本アプリをブラウザで開き、右上の「**設定**」ボタンをクリックします。
6. コピーしたAPIキーを貼り付け、「**設定を保存**」をクリックします。

> [!NOTE]
> 入力したAPIキーは、外部のサーバーには送信されず、お使いのブラウザのローカルストレージ（Local Storage）にのみ暗号化等はされませんが安全に保存されます。いつでも「設定」内の「APIキーを消去」ボタンから削除可能です。

## 授業や指導での活用シナリオ

### ① 自習用ツールとしての配布
フォルダ丸ごと（`index.html`、`style.css`、`app.js`、`README.md`）をZipファイルに圧縮し、学内ポータルやOneDrive経由で学生に配布します。
学生は各自Google AI Studioでキーを取得するか、または先生が取得したキーを入力させて使用します。

### ② 講義・演習中でのリアルタイム活用
学生に「スマホやPCでこのアプリを起動しながら、放射化学の計算演習に取り組む」よう指示します。
答えを教え合うのではなく、AIから出されるヒントに基づいて「どの公式を使うべきか」「周期表のどこを見るべきか」を対話させながら解かせます。

## カスタマイズ方法（過去問の追加など）
独自の過去問やオリジナルの計算問題をテンプレートに追加したい場合は、`app.js` ファイルの冒頭にある `questionTemplates` オブジェクトをテキストエディタで編集することで、簡単に追加・修正できます。

```javascript
const questionTemplates = {
    // 新しい問題を追加する例
    q_new: {
        title: "新規問題のタイトル",
        text: "【国試過去問】問題文をここに記述します...",
        initialPrompt: "AIへの最初のリクエスト内容（この問題の解き方をステップバイステップで誘導して、等）"
    },
    ...
}
```
そして、`index.html` 内の `.template-list` に対応するボタンを追加してください。
```html
<button class="template-btn" data-qid="q_new">
    <span class="tag tag-calc">計算</span>
    <span class="txt">新規問題のタイトル</span>
</button>
```
これで、新しい問題が画面に追加されます。
